## summary
This project is my idea for how AI can help people in daily life.
My idea is a simple AI helper that gives easy answers and guidence to students and small shopkeepers in pakistan.
##Problem
Many people do not understand AI and do not know how it can help them in study, work and business.

##Solution
This project explains in simple words how AI works and how we can use it for learning, making decisions and saving time.

I learned what AI is, how data and machine learning work, and how to present an idea clearly on GitHub.
